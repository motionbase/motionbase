MotionBase Design System

Referenz für eigenständige Grafiken und interaktive Elemente. Alles hier ist reines HTML/CSS ohne Abhängigkeiten — kopierbar in jede Datei, die über den Interaktiv-Block eingebunden wird.

Farben

Ein Akzent, sonst Graustufen. #ff0055 ist reserviert für das, worauf es ankommt: das bewegte Objekt, die Datenkurve, den aktiven Zustand. Wird es zur Dekoration benutzt, verliert es genau die Wirkung, für die es da ist.

zinc-400 (#a1a1aa) nicht für Text. Auf Weiß erreicht es 2,6:1 und fällt damit unter die WCAG-AA-Schwelle von 4,5:1. Gemessen in der UX-Prüfung der Kursansicht. Für sekundären Text ist --muted (#71717a, 4,8:1) die hellste sichere Stufe.

Typografie

Inter, mit aktivierten Stilsätzen. Ohne font-feature-settings sehen Ziffern und das „a“ anders aus als in der App — daran erkennt man sofort, dass eine Grafik nicht dazugehört.

Zum Kopieren

Der komplette Token-Block. Gehört an den Anfang jeder neuen Grafik.

:root {
  --brand: #ff0055;
  --brand-soft: rgba(255, 0, 85, 0.14);
  --brand-line: rgba(255, 0, 85, 0.35);

  --ink: #18181b;
  --ink-soft: #3f3f46;
  --muted: #71717a;
  --faint: #a1a1aa;        /* nur dekorativ, nicht für Text */

  --line: #e4e4e7;
  --line-soft: #f4f4f5;
  --line-strong: #d4d4d8;

  --surface: #ffffff;
  --surface-muted: #fafafa;

  --radius-lg: 1rem;
  --radius-md: 0.75rem;
  --radius-sm: 0.5rem;

  --font: 'Inter', 'Inter var', ui-sans-serif, system-ui, -apple-system,
          BlinkMacSystemFont, 'Segoe UI', sans-serif;
}

html, body {
  margin: 0;
  font-family: var(--font);
  font-feature-settings: 'ss01', 'ss02', 'cv01', 'cv02';
  -webkit-font-smoothing: antialiased;
  background: var(--surface-muted);
  color: var(--ink);
}

Einbettung

Zwei Dinge, ohne die jede Grafik im Kurs falsch aussieht: die eigene Rahmung muss weg (sonst Karte in Karte), und die Höhe muss gemeldet werden (sonst Scrollbalken). Details in README.md im selben Ordner. 

<!-- im <head>, VOR dem <style> -->
<script>
  if (window.parent !== window) document.documentElement.classList.add('is-embedded');
</script>

/* im CSS */
.is-embedded, .is-embedded body { overflow: hidden; }
.is-embedded body { padding: 0; background: transparent; }
.is-embedded .app-card { width: 100%; border: 0; border-radius: 0; }

/* am Ende des Scripts */
let lastReportedHeight = 0;

function reportHeight() {
  if (window.parent === window) return;

  // Body-Box, NICHT documentElement.scrollHeight: letzteres unterschreitet nie
  // den Viewport des Iframes, die Höhe könnte dann nur wachsen, nie zurück.
  const height = Math.ceil(document.body.getBoundingClientRect().height);
  if (height === lastReportedHeight) return;

  lastReportedHeight = height;
  window.parent.postMessage({ type: 'motionbase:resize', height }, '*');
}

window.addEventListener('resize', reportHeight);
if (typeof ResizeObserver !== 'undefined') new ResizeObserver(reportHeight).observe(document.body);
reportHeight();
Sandbox beachten. Grafiken laufen unter Content-Security-Policy: sandbox allow-scripts auf einer Opaque Origin. Kein localStorage, keine Cookies, keine Requests an die App. Canvas, SVG, CSS-Animationen und Inline-JS funktionieren uneingeschränkt. Externe Dateien werden nicht ausgeliefert — alles muss inline sein.
